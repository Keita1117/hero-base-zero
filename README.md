# HERO BASE ZERO（ヒーローベース ゼロ）

4歳のお子さまが YouTube の受け身視聴から卒業し、**「自分が隊長になって相棒メカ『レックス・ゼロ』を育てる」** かっこいい系・総合知育 PWA アプリです。

---

## 搭載している 7 つの学習＆創造ドック

1. **⚡ ひらがな レーザー**：46文字なぞり書き（レーザー＆火花演出・音声ガイド）／ことばレーダー／もじがったいパズル
2. **🔢 かず＆とけい ラボ**：1〜20 タップ数え／視覚的な足し算・引き算／アナログ時計クイズ＆操作練習
3. **🤖 ロボ・コマンド**：5×4 宇宙マップ（全12ステージ）のプログラミング指令＋図形・パターン推理
4. **🚀 エイゴ ステーション**：A〜Z サウンドボード＆ネイティブ英語発音リスニングクイズ
5. **📷 リアル たんけんスキャナー**：カメラで身の回りの「色」や「お気に入り」をスキャンして図鑑登録（色判定付き＋写真/いろカード対応）
6. **🎨 ビート＆うごくアトリエ**：描いた絵が宇宙ステージで動き出すお絵かき＋8ステップビートメーカー＆虹色ピアノ
7. **🦖 ヒーローしれい＆メカドック**：3分間はみがきタイマー付き生活習慣＋相棒メカ5段階進化・カラー＆装備カスタマイズ

### 保護者のための安全・やめ時設計
- **自律おやすみタイマー**：残り3分で画面が穏やかな夕焼け色に変化し、時間になるとメカが眠る「おやすみ画面」がロックされます。
- **保護者ゲート**：設定変更・解除は簡単な掛け算認証を通過した大人だけが操作できます。
- **完全オフライン対応**：Service Worker + localStorage + IndexedDB により、ネットワークなしでも動作します。

## 1. Windows PC での即起動方法

フォルダ内の `start_server.ps1` を PowerShell で実行し、ブラウザで `http://localhost:8765` を開きます。

```powershell
.\start_server.ps1
```

## 2. Android タブレットへの導入手順（GitHub Pages 無料 HTTPS 公開・3分）

Android Chrome で **PWA「ホーム画面に追加」** と **ライブカメラ起動** を有効にするには HTTPS 配信が推奨されます。ビルド不要のため、そのまま公開できます。

1. GitHub で新しいリポジトリ（例：`hero-base-zero`）を作成し、このフォルダの中身をすべてアップロード（または `git push`）。
2. リポジトリの **Settings > Pages > Source** で `Deploy from a branch`（`main` / `/(root)`）を選択して保存。
3. 発行された `https://<アカウント名>.github.io/hero-base-zero/` を Android タブレットの Chrome で開く。
4. Chrome 右上メニュー `⋮` → **「ホーム画面に追加」→「インストール」** をタップ。
5. 以降、ホーム画面のヒーローアイコンから **全画面・アドレスバーなし・オフライン** で起動できます。

> [!TIP]
> ローカルWi-Fi配信（`http://192.168.x.x:8765`）でも動作確認できますが、Androidの仕様上 HTTP 接続ではライブカメラ(`getUserMedia`)が制限されるため、カメラは自動的に「しゃしんを とる／えらぶ」へ切り替わります。フル機能には GitHub Pages（HTTPS）をおすすめします。

## 3. YouTube 脱走防止：「アプリの固定（画面ピン留め）」設定

タブレットをお子さまに渡す際、Android 標準機能を使うと YouTube やホーム画面へ切り替えられなくなります。

1. Android の **「設定」→「セキュリティとプライバシー（または生体認証とセキュリティ）」→「アプリの固定」** を ON にする（画面ロック時の PIN も併用設定）。
2. `HERO BASE` を全画面で開く。
3. 画面下からのスワイプ（またはナビゲーションバーの `□`）でアプリ切り替え画面を開く。
4. `HERO BASE` のアイコンをタップ → **「固定（ピン留め）」** を選択。
5. 解除したいときだけ、大人が指定ボタン長押し＋端末PINで解除します。

## 4. お題・ことばのカスタマイズ方法

`js/data.js` の先頭付近にある以下の配列を編集するだけで、お子さまの好きな乗り物・キャラクター・お家のルールに合わせて簡単にお題を増やせます。

- `HIRAGANA_LIST` / `WORD_PUZZLES`：なぞりヒントや合体パズルの単語
- `ENGLISH_ALPHABET` / `ENGLISH_QUIZ_ITEMS`：英語ボードとクイズ単語
- `ROBO_STAGES`：ロボットパズルのステージマップ
- `DAILY_HABITS`：毎日の生活習慣チェック項目（`はみがき`・`おかたづけ` など）
